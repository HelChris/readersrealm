# Readers Realm - journey through the pages together

An app for getting together sharing thoughts about books.

## Description

##### Goal
To apply knowledge of JavaScript techniques to implement the front-end functionality for a social media application.

##### API
The API used for this project can be found under Social Endpoints in the Noroff API v2 documentation.

### Brief
YPlan, design and build an social media app using the Noroff API with social endpoints. The client application must be attractive and responsive, but you have an otherwise blank slate in terms of theme design language.

Using the provided API and API documentation, I created a functioning user interface that allows for viewing, posting, editing and deleting social media content.

Social API routes require both a JWT token and an API Key. Use the GET, POST, PUT, and DELETE HTTP methods. Use JSDocs to document at least one function. The minimum requirement is one example of well written JSDocs for a function that includes argument types, return types, a description and a usage example. Use localStorage for storing JWT tokens.


### Required features / user stories:

- User with @noroff.no or @stud.noroff.no email can register profile
- Registered user can login
- User can view a post content feed
- User can filter the post content feed
- User can search the post content feed
- User can view a post content item by ID
- User can create a post content item
- User can update a post content item
- User can delete a post content item

## Getting Started

### Installing


1. Clone the repo:

```bash
git clone https://github.com/HelChris/readersrealm.git
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
